## 1. What's in this tarball

打开后 `probe/...` 是相对路径根目录。19 个文件:

```
probe/
├── probe_canonical.json                            # 1.8K  ← 标准答案:sha256 + expected val_acc
├── h_stock.pt                                       33 M   ← backbone hidden dump (basemodel)
├── h_kf.pt                                          33 M   ← M1 (kf-only) hidden dump
├── h_kfvlm.pt                                       30 M   ← M1v (kf+VLM stage) hidden dump
├── h_wrongstage.pt                                  35 M   ← M1v_WRONG (Ablation-3, step 200) hidden dump
├── reproduce_out/
│   └── reproduce_summary.json                       712 B  ← 上次 PASS/FAIL 自检
└── out_h_<tag>/                                            ← × 4 个 tag (stock/kf/kfvlm/wrongstage)
    ├── results_robotwin_train_h_hidden_vlm_stage.json   ~1.1K  ← 完整 metrics
    ├── probe_robotwin_train_h_hidden_vlm_stage.pt        76K   ← 线性探针权重
    └── tsne_robotwin_train_h_hidden_vlm_stage.png       ~120K  ← t-SNE 图(色按 VLM 阶段)
```

### 各文件含义

| 文件 | 说明 |
|---|---|
| `probe_canonical.json` | 标准答案:每个 dump 的 sha256 + expected val_acc/train_acc + 元信息(seed、阶段类数、容忍度等)。reproduce_probe.sh 用它做 PASS/FAIL 校验 |
| `h_*.pt` | 上游"中间产物":每帧 backbone hidden(3072 维)+ kf 阶段 + VLM 阶段 + episode id。由 `wan_va.train --probe-collect` 离线 forward 一次得到 |
| `out_h_<tag>/results_*.json` | 完整探针指标:val_acc / train_acc / 高于随机 / per_class / 6×6 混淆矩阵 / 样本数 |
| `out_h_<tag>/probe_*.pt` | 训好的 `nn.Linear(3072→6)` 权重(供他人做干预实验/特征可视化) |
| `out_h_<tag>/tsne_*.png` | 真 t-SNE(sklearn,perplexity 默认),色按 VLM 阶段。可直接放报告 |
| `reproduce_out/reproduce_summary.json` | 上次复跑结果对照表(actual val_acc vs expected,PASS/FAIL,tolerance ±0.01) |

### 报告里直接用的三句

- **kfvlm vs kf:Δ = +0.130** —— VLM 语义监督的纯贡献(单调跨越主结果)
- **wrongstage vs stock:Δ = -0.014** —— 错误监督**有害**(不是中性),反事实证据
- **wrongstage vs kfvlm:Δ = -0.140** —— 信号正确性的因果效应(M1v 提升来自"正确的"信号,非"任何 aux head 都涨")

泛化差(train_acc - val_acc)从 stock 0.319 单调收窄到 kfvlm 0.104,说明
**M1v 不是"过拟合 VLM 标签",而是把任务阶段结构学进了 backbone**。

## 3. How to reproduce(无需 GPU,~1 分钟)

### 3.1 解压

```bash
TGT=/some/path/to/extract
mkdir -p $TGT
tar xzvf wam_cot_probe_full_20260520_081205.tgz -C $TGT
ls -R $TGT/probe
```

### 3.2 装最小依赖

```bash
pip install numpy torch scikit-learn matplotlib safetensors
```
(只要 CPU 版的 torch 即可,无需 GPU。)

### 3.3 跑探针 + 与 canonical 对照(一条命令)

```bash
git clone <项目 repo url>
cd <repo>
PROBE_DIR=$TGT/probe bash script/reproduce_probe.sh
```

末尾期望输出:
```
============================  对照表  ============================
tag               val_acc expected        Δ    tol  status
h_stock             0.652    0.652   +0.000  0.010  PASS
h_kf                0.648    0.648   +0.000  0.010  PASS
h_kfvlm             0.778    0.778   +0.000  0.010  PASS
h_wrongstage        0.638    0.638   +0.000  0.010  PASS

==>  ALL PASS (within ±0.01)
```

### 3.4 (或)只跑单个 dump

```bash
python evaluation/robotwin/latent_probe.py \
    --config robotwin_train \
    --features h_hidden --label vlm_stage \
    --hidden-dump $TGT/probe/h_kfvlm.pt \
    --out-dir /tmp/single_probe_out \
    --seed 0
# 输出 results_*.json + probe_*.pt + tsne_*.png 三件
```

## 4. Probe settings(可复制进报告"探针细节"小节)

- **linear probe**:`nn.Linear(3072 → 6)`,AdamW(lr=1e-3),50 epoch,字节级确定性(`torch.manual_seed(args.seed)` 控制 init)
- **input feature**:`kf_feat = pred[3]` from `forward_train`,即 backbone 在 `proj_out` 之前对空间维 mean-pool 的隐状态(每 latent 帧 d=3072 维)
- **label**:6 个真实 VLM 阶段(来自 `stages.jsonl`,Qwen3.5-VL 4B 离线对每集采 4 帧生成,12 任务 × 500 ep 全覆盖)
- **split**:按 episode(轨迹安全,`seed=0`)—— 防止"同轨迹相邻帧相似"导致探针作弊
- **chance**:1/6 ≈ 0.167(若问"为什么不是 1/8":虽然 `vlm_num_stages=8` 但实际数据集里有效阶段数 6)
- **tolerance**:±0.01(sklearn / numpy 跨版本可能有 <0.005 抖动,留一倍安全余量)
